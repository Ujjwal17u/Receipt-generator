# ReceiptAI — Premium AI Receipt Generator

A professional, polished receipt generator with live preview, QR codes, itemized details, GST support, PDF export, and offline-first persistence.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Stack

- TanStack Start (SSR + file-based routing)
- TypeScript 5
- React 19
- Tailwind CSS v4
- Express 4 + Mongoose 8 (optional backend API)
